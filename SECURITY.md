# Reporting Security Issues

The Ohtia maintainers take security issues seriously and appreciate responsible disclosure. Please do not report a vulnerability through a public issue, discussion or pull request.

## How to report

Report a vulnerability privately through GitHub's [Report a vulnerability](https://github.com/ohtia/ohtia/security/advisories/new) form, under the repository's Security tab.

If you cannot use the GitHub form, email [security@ohtia.com](mailto:security@ohtia.com).

## What to expect

The maintainers acknowledge your report within 6 business days. After that first reply, they keep you informed of progress towards a fix and its announcement, and may ask for more information or guidance. A report never goes more than 14 days without a response.

## Escalation

If a report sent through the GitHub form receives no acknowledgement within 6 business days, email [security@ohtia.com](mailto:security@ohtia.com). If a report sent by email receives no acknowledgement within 6 business days, use the GitHub form.

## Disclosure

Fixed vulnerabilities are published as [GitHub security advisories](https://github.com/ohtia/ohtia/security/advisories), crediting the reporter unless they ask not to be named.

Security fixes are made on `main` and delivered according to the [release policy](docs/release-policy.md).

## Third-party components

Report a vulnerability in a dependency to that dependency's maintainers. Report it to Ohtia as well when Ohtia's use of the dependency makes it exploitable.
