# EPIC-001 — Desktop foundation

- [EPIC-001 — Desktop foundation](epic.md) - Deliver a safe runnable desktop, reproducible native contribution environments and verified immutable build/release infrastructure.

## Stories

- [STORY-001-001 — Qualify the desktop target and delivery contracts](STORY-001-001-qualify-the-desktop-target-and-delivery-contracts.md) - Define reviewed required/optional target tooling, provisional delivery mechanisms and one numeric resource contract without waiting for native probe execution.
- [STORY-001-002 — Establish the locked workspace and developer toolchain](STORY-001-002-establish-the-locked-workspace-and-developer-toolchain.md) - Provide working package boundaries and isolated, frozen JavaScript and Python tooling.
- [STORY-001-003 — Define and verify the bounded application port](STORY-001-003-define-and-verify-the-bounded-application-port.md) - Provide versioned runtime-validated IPC operations and error contracts for the foundation.
- [STORY-001-004 — Run the isolated desktop and supervised data service](STORY-001-004-run-the-isolated-desktop-and-supervised-data-service.md) - Launch a minimal graphical Electron application with a single broker, fixed-home bootstrap and a supervised utility process.
- [STORY-001-005 — Persist a minimal command with verified migration recovery](STORY-001-005-persist-a-minimal-command-with-verified-migration-recovery.md) - Demonstrate file-backed durability, exclusive migrations and verified checkpoint recovery through the real desktop path.
- [STORY-001-006 — Implement bounded diagnostics without private content](STORY-001-006-implement-bounded-diagnostics-without-private-content.md) - Emit validated content-free diagnostics through one bounded broker-owned writer.
- [STORY-001-007 — Enforce shared verification and coverage gates](STORY-001-007-enforce-shared-verification-and-coverage-gates.md) - Run the same meaningful types, lint, format, test, coverage and build checks locally and in CI.
- [STORY-001-008 — Provide the reproducible sandboxed Linux E2E environment](STORY-001-008-provide-the-reproducible-sandboxed-linux-e2e-environment.md) - Reproduce real Electron tests in an immutable Linux environment with active sandboxes.
- [STORY-001-009 — Make Linux contribution setup reproducible](STORY-001-009-make-linux-contribution-setup-reproducible.md) - Enable a new Linux contributor to install, diagnose, run and verify Ohtia from a clean checkout.
- [STORY-001-010 — Make Windows contribution setup reproducible](STORY-001-010-make-windows-contribution-setup-reproducible.md) - Enable a new Windows contributor to install, diagnose, run and verify Ohtia through a native supported path.
- [STORY-001-011 — Make macOS contribution setup reproducible](STORY-001-011-make-macos-contribution-setup-reproducible.md) - Enable a new macOS contributor to install, diagnose, run and verify Ohtia on required Apple Silicon, with independently qualified optional Intel support.
- [STORY-001-012 — Build and smoke-test native quality artifacts](STORY-001-012-build-and-smoke-test-native-quality-artifacts.md) - Produce isolated, identifiable quality packages and complete native smoke evidence for PRs and integrated source.
- [STORY-001-013 — Qualify signed installation and update mechanisms](STORY-001-013-qualify-signed-installation-and-update-mechanisms.md) - Verify final signed installers and authentic compatible updates on the complete declared desktop matrix.
- [STORY-001-014 — Capture and assemble reviewed user change notes](STORY-001-014-capture-and-assemble-reviewed-user-change-notes.md) - Collect PR impact statements and assemble traceable channel-specific editorial release notes.
- [STORY-001-015 — Prepare immutable candidates through trusted authority](STORY-001-015-prepare-immutable-candidates-through-trusted-authority.md) - Reserve versions and assemble retained, fully verified final candidates through an explicitly invoked trusted workflow.
- [STORY-001-016 — Promote and reconcile exact release artifacts](STORY-001-016-promote-and-reconcile-exact-release-artifacts.md) - Publish authorized candidate bytes with serialized promotion, failure reconciliation, retention and withdrawal.
- [STORY-001-017 — Verify the integrated foundation and contributor journeys](STORY-001-017-verify-the-integrated-foundation-and-contributor-journeys.md) - Demonstrate the full foundation, three native contributor paths and release infrastructure with traceable acceptance evidence.
- [STORY-001-018 — Qualify the native foundation targets](STORY-001-018-qualify-the-native-foundation-targets.md) - Prove frozen workspace installation and native runtime, addon, filesystem and delivery-mechanism feasibility on all required targets.
