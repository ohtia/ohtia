# EPIC-002 — Basic interface

- [EPIC-002 — Basic interface](epic.md) — Deliver accessible localized desktop menus, an integrated title bar, workspace controls, a command palette, extensible Settings and shared visual primitives.

## Stories

- [STORY-002-001 — Build canonical tokens, bundled fonts and static branding](STORY-002-001-tokens-fonts-and-branding.md) — Every delivered token matches its canonical definition; missing aliases, unlisted pairs and altered font bytes fail.
- [STORY-002-002 — Extend typed localization and global language selection](STORY-002-002-typed-localization.md) — Deliver the shared locale service, complete own-scope JSON catalogs for all 25 locales and durable language selection.
- [STORY-002-003 — Deliver semantic primitives and the separate catalog](STORY-002-003-semantic-primitives.md) — All delivered variants/states expose the required semantics and preserve input/focus through failure.
- [STORY-002-004 — Unify named commands, native menus and About](STORY-002-004-commands-native-menus-about.md) — Deliver the shared command registry, native menus and a functioning local Help/About surface.
- [STORY-002-005 — Implement deterministic workspace geometry and preferences](STORY-002-005-workspace-controller.md) — Numerical geometry examples and all seven nonempty visibility combinations preserve minima and sum.
- [STORY-002-006 — Compose accessible, responsive workspace chrome](STORY-002-006-workspace-chrome.md) — Context controls, geometry, keyboard/pointer resizing, hiding/restoration and narrow reflow preserve in-session state.
- [STORY-002-007 — Provide extensible Settings and durable presentation choices](STORY-002-007-extensible-settings.md) — Provide compact Settings and validated appearance, character and zoom controls with durable receipts.
- [STORY-002-008 — Deliver character modes and distinct contributor identities](STORY-002-008-character-presentation.md) — Static/Hidden/reduced-motion changes cancel motion/deferred events immediately without replay on re-enable.
- [STORY-002-009 — Build attributed research component specimens](STORY-002-009-research-component-specimens.md) — Specimens preserve evidence/inference/human attribution and never make confirmation or scientific correctness claims.
- [STORY-002-010 — Qualify integrated pages and native assistive journeys](STORY-002-010-native-interface-qualification.md) — Verify the frozen integrated candidate through native, keyboard and assistive journeys on all required targets/profiles.
- [STORY-002-011 — Validate localized catalogs and contributor identity](STORY-002-011-linguistic-identity-review.md) — Validate all 25 integrated catalogs, model-generation provenance and contributor identity without requiring human linguistic review.
- [STORY-002-012 — Compose the application root](STORY-002-012-compose-application-root.md) — Connect the delivered interface components into a real application and freeze one verification candidate.
- [STORY-002-013 — Deliver the integrated title bar and native window state](STORY-002-013-native-window-chrome.md) — Each workspace window uses one integrated title-bar row, opens without a white first frame and restores saved bounds onto a connected display.
- [STORY-002-014 — Deliver the command palette and keyboard shortcuts help](STORY-002-014-command-palette-and-shortcuts.md) — A registry-generated command palette and keyboard-shortcuts dialog list only real commands with their shortcuts and truthful availability.
