# STORY-003-033 — Project memory view and entries

## Acceptance criteria

- [ ] A goal or decision shows "From your message · worded by Virgilio" with the quoted start of its message and "Go to message".
- [ ] The memory view, its loading and failure states and its entry form show their texts, with plural forms, and "Withdraw entry" asks first.
- [ ] "Add memory entry…" is the last always-visible icon button of every message's actions row in a confirmed project and absent in the setup conversation; its form opens inline in the tab, with "Kind" at "Decision" for a researcher message and at "Note" with an empty text otherwise, recording the message it opened from as the source; history rows read "{change} · {author} · {date}" with the name of each `change` value, "Merged into another entry" and "Withdrawn by Undo" included, an undo reading "Written by you"; a withdrawn entry offers only "Show entry history".
- [ ] Of two windows editing the same entry, the second keeps its text with "This entry changed in another window. Your text is kept. Save it to replace that version."
- [ ] Each command rejection returns `entry_invalid`, `memory_full` or `stale_revision` with its notice, saving nothing.
- [ ] The researcher adds, edits, withdraws and reads history without spending.
- [ ] An entry the researcher wrote or edited cannot be changed by Virgilio and reads "Written by you" or "Recorded by Virgilio · edited by you".
- [ ] "Open project memory" on the memory-change line opens the tab, and a rejected undo there shows "Ohtia can't undo these changes because an entry has changed since. Edit it in the project memory instead."
- [ ] A researcher's edit marks a reply based on the old version (scenario 12); a memory change from another window, Virgilio or an undo raises the memory revision, and the open tab and histories read it again, also after a `sequence_gap`.
- [ ] `docs/workspace-layout.md` lists the Project memory entry and tab, and `docs/design-system.md` maps `notebook-text` and `notebook-pen` as stated.
- [ ] With the researcher's account, an entry added from a message is used by Virgilio in another conversation, and editing an entry marks the old reply.
