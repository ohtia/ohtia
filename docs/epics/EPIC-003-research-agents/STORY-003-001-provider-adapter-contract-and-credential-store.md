# STORY-003-001 — Provider adapter contract and credential store

## Description

Implement the ADR-0026 adapter contract shared by every provider (declaration, connection states and operations, fake provider and conformance suite), the connection operations in main and the credential service on `@napi-rs/keyring` in the main process. Main holds every credential and handles every connection operation; the data service only receives each connection's state and model list. This story adds no interface: Sign in with ChatGPT and Settings › Connections are STORY-003-002, and sending requests is STORY-003-003.
