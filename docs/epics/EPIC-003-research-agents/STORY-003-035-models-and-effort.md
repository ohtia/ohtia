## Acceptance criteria

- [ ] Changing service waits for a model choice and never picks one automatically.
- [ ] A failed list, or one that fails on a later page, keeps choices and marks no model gone, and queued tasks keep their settings after a preference change.
- [ ] A stored list of 1,500 models reaches the selects through `providerModel.list` pages that each stay within every port bound, every model appears in order, and a page read after the list changed returns `stale_revision` and is read again from the first page.
- [ ] A model the service marks as deprecated is not offered, and declared-unsupported and unknown effort show their own texts.
- [ ] A disappearing model blocks the reply with `configuration_unavailable`, its notice and destination line, and a plan row with its text, and choosing another model starts it without a new message; a contribution task keeps its connection and its notice offers no other model; a reply's "Try again" uses the current preference, while a contribution's or synthesis's keeps the recorded connection.
- [ ] "Refresh {service} model list" announces its progress and uses the vendored `list-restart` icon, each connected service has its own button with a distinct name, and connecting a second service shows its notice.
- [ ] A first connection without a default asks inline in its Connections row, below the state line and above the row's buttons, which stay available, with focus on "Model", the first model preselected, no dismiss button and no dialog over Settings; the row keeps the question until a default model is saved, and hides it while the connection is not `connected` or its model list has no model.
- [ ] `contribution.tryAgain` and `synthesis.tryAgain` accept a task cancelled with `destination_changed` and reject any other cancelled task with `task_not_retryable`.
- [ ] "Default model" and each agent have their own three selects; after a service change the effort select is disabled with "Choose a model first."; the list age uses the locale's relative-time format; "Requested effort" reads "Model default" when no effort was sent.
- [ ] Saving a preference that moves an agent to another connection fails its blocked contribution, consultation or synthesis task with `destination_changed` and the "Not sent" text, the plan needs attention when the contribution is required, and "Try again" is rejected with `destination_changed` until the approved connection is chosen again; the contribution keeps that `failure_reason` beside its cancelled task until the retry that creates its next task clears it.
- [ ] A model change that lacks the saved effort resets it to "Model default"; an upgrade with stored tasks sets the default from the first list with the source `migration` and no question, while a first connection without any task asks the first-connection question.
- [ ] ChatGPT models store effort as `unknown`, `provider_models` stores the account fingerprint and no email, and the Settings texts show `{value}` as the select's label.
- [ ] With the researcher's account, Josefa's model changes and "Details" shows it, and the fields of the account's list entries are recorded in the pull request.
