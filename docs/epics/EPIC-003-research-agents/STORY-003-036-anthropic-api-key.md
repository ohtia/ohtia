# STORY-003-036 — Anthropic API key

## Description

Add the Anthropic API-key connection, model listing with effort levels, Messages requests through `@anthropic-ai/sdk` in the main process with mapped tools and text history, event and stop-reason handling, and error mapping with rate-limit waits and billing pauses, with every text taking `{service}` and the `api_key` variant. The key goes from the window to main only and never reaches the data service.
